# Decoder Ring

Decoder Ring is a JavaScript application developed as part of the Thinkful Software Engineering program. The application encodes and decodes messages using three classic cipher techniques: Caesar Shift, Polybius Square, and Substitution Cipher.

## Application Overview

The project focuses on JavaScript programming, algorithm development, input validation, data transformation, and unit testing.

The three cipher implementations demonstrate different programming techniques:

* **Caesar Shift** — shifts alphabetic characters while supporting positive and negative shifts, alphabet wraparound, encoding, and decoding.
* **Polybius Square** — maps characters to coordinates in a two-dimensional grid and converts those coordinates back into characters.
* **Substitution Cipher** — maps characters between the standard alphabet and a user-supplied substitution alphabet while validating the substitution key.

The implementations also preserve appropriate spaces and nonalphabetic characters and validate input according to the requirements of each cipher.

## My Implementation

Thinkful provided the HTML, CSS, application framework, project requirements, and a set of automated tests.

My work focused on implementing the JavaScript cipher algorithms in the `src` directory and adding unit tests in the `test` directory. The implementations use JavaScript techniques including arrays, iteration, higher-order functions, regular expressions, string manipulation, two-dimensional data structures, input validation, and reusable helper functions.

I also used techniques beyond those specifically covered at that point in the curriculum, including regular expressions and `while` loops, where they provided a natural solution to the problem.

## Personal Connection

This project was particularly enjoyable for me because it revisited one of my earliest programming experiences. In high school, an extra-credit programming assignment challenged me to develop an encode/decode cipher algorithm in Pascal. Implementing three different cipher algorithms in JavaScript many years later brought that experience full circle.

## Testing

The project uses Mocha and Chai for automated unit testing. In addition to the supplied project tests, I created tests covering input validation and expected encoding and decoding behavior for each cipher.
